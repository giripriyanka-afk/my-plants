# My Plants App

## Scope
It's an single-user app for the user to create, edit and delete a list of plants and track watering, fertilizing, pruning and repotting actions. Default period per action is 2 weeks. It can be adjusted by the user.
All data is stored in localStorage - no backends or user accounts yet

## Stack
- next.js with the App Router
- Typescript
- Tailwind CSS

## Running the app
Run 'npm run dev'. The app runs at http://localhost:3000

## Conventions
- ask before making any feature or settings changes
- ask if anything is vague or unclear

## Do not
- Add npm packages without asking first
- Put secrets or API keys in source files — use .env.local for environment variables
