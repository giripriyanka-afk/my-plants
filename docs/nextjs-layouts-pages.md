Source: https://nextjs.org/docs/app/getting-started/layouts-and-pages
---
Pages can be created by adding a folder with the name of the route and a page.tsx file
inside it. For example, to create a page at /about, add app/about/page.tsx.

A page file exports a default React component:

  export default function Page() {
    return <h1>Hello, Next.js!</h1>
  }
